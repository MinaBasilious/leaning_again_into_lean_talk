# The mini course

Lean together with the type theory behind it, for people with no background in
either. The aim is to be able to read what a machine certifies, not only to run
the checker.

## Plan

Three weekly lectures with exercises in between. Each lecture opens with the
type theory on the board, then moves to hands-on work in Lean. Core Lean 4 only,
no Mathlib, so that automation does not solve the exercises.

- **Week 1:** types versus sets, the Curry-Howard correspondence, first-order
  logic in Lean.
- **Week 2:** inductive types, focusing on the natural numbers and induction.
- **Week 3:** sets as types, and an optional session on how mathematicians use
  Lean on larger projects, including working with AI tools.

## After three weeks

You can translate a statement between informal mathematics and Lean in both
directions, prove basic facts about arithmetic and logic, and spot a trap like
`dist` without running anything.
